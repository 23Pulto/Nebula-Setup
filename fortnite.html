Setting Up Fortnite External

A professional, step-by-step guide to installing and configuring the Nebula external tool for Fortnite.

Start Setup

Installation Process

Follow these steps carefully. Fortnite's external tool requires specific Nvidia configurations.

01

Download & Extract

Download the latest release. Once downloaded, extract the ZIP file to a dedicated folder on your desktop.

https://github.com/23Pulto/Fortnite-External/releases
02

Security Exceptions

Add the extracted folder to your Windows Defender exclusions. An easier way is to simply **disable your Anti-Virus** real-time protection while using the tool to prevent any blocks.

03

Install Dependencies

Install both the Visual C++ Redistributable and the DirectX Runtimes to ensure the application can launch and render the overlay.

Download VC++ Redist Download DirectX
04

Nvidia App Configuration

The external tool hooks into the **Nvidia Overlay**. You must have the Nvidia App installed.

⚠️
Important: If you already have the Nvidia App, you must uninstall it and then reinstall it. When prompted during installation, Enable the Overlay.

Do NOT create or log into an account. Use the app as a guest.

A PC restart may be required after the reinstallation for the overlay to function correctly.
05

Launch & Activate

Right-click the application and select "Run as Administrator". Follow the prompts in the terminal and enter your license key when requested.

Status: Waiting for Key...
06

Launch Fortnite

Start Fortnite. Ensure your game is in Windowed Fullscreen and using DirectX 11 or 12. Once you are in the lobby, **press "Y" on your keyboard** to activate the overlay menu.

Common Issues

Overlay not showing?

Ensure Nvidia Overlay is enabled in the Nvidia App settings. If it still doesn't show, perform a clean reinstall of the Nvidia App without logging in.

Application crashes on start?

Ensure you are running as Administrator and your Anti-Virus is completely disabled.
