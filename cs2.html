Setting Up CS2 External

A professional, step-by-step guide to installing and configuring the Nebula external tool for Cs2.

Start Setup GitHub Repo

Installation Process

Follow these steps in order to ensure maximum compatibility and performance.

01

Download & Extract

Get the latest release from the official repository. Once downloaded, extract the ZIP file to a dedicated folder on your desktop.

https://github.com/23Pulto/Cs2-External/releases
02

Security Exceptions

To prevent Windows Defender from blocking the driver mapping, add the extracted folder to your Virus & Threat Protection exclusions or disable real-time protection temporarily.

Settings > Security > Virus & threat protection > Manage settings > Add or remove exclusions.

03

Install Dependencies

Ensure you have the latest Visual C++ Redistributable packages installed. This is required for the user-mode GUI and kernel communication.

Visual C++ Redistributable 2015-2022 Download
04

Launch Nebula

You have two options for launching Nebula depending on the version and your preference:

⚠️
Kernel Warning: Using the Kernel file provides enhanced stealth but may cause Blue Screening (BSOD) on some systems. This is not harmful to your PC, but it can be annoying.

Recommended: It is always safest and recommended to stick to Usermode.

Note: Sometimes in newer updates, the Kernel file may not be included due to stability issues. If it's missing, simply run the Usermode file.

Option A (Stealth): Run the Kernel file first, then the Usermode file as Administrator.

Option B (Safe): Just run the Usermode file as Administrator. Then follow the steps in the terminal.

05

Launch the Game

Finally, launch Counter-Strike 2. Ensure your display mode is set to Windowed or Fullscreen Borderless for the menu to appear.

Status: Setup Complete

Common Issues

Encountering problems? Check these common fixes below.

Why can't I see the menu?

This is usually caused by your game being in "Fullscreen" mode. Go to the in-game settings and select Windowed or Fullscreen Borderless. The overlay cannot render over a native Fullscreen window.

The application closes immediately upon opening.

Ensure you have added an exclusion for the folder in Windows Defender. Defender often deletes or blocks the files without notification.

"VCRUNTIME140.dll" or "MSVCP140.dll" missing.

You are missing the Visual C++ Redistributables. Please go back to Step 03 and download the 2015-2022 pack.

Does this work on FACEIT ?

No. Nebula currently does not work on FACEIT. Using it on FACEIT will probaly get you VAC banned almost instantly. This might change in the future.
