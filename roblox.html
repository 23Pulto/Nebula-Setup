Setting Up Roblox External

A professional, step-by-step guide to installing and using the Nebula Roblox external.

Start Setup

Installation Process

Follow these steps in order to ensure your external is fully working.

01

Download Release & Extract

Get the latest release from the official GitHub repository. Once downloaded, extract the ZIP folder to a dedicated location on your desktop or a folder of your choice.

https://github.com/23Pulto/Roblox-external/releases/tag/Updates
02

Security Exclusions (Important)

To prevent Windows Defender from deleting or blocking the external, add the extracted folder to your Virus & Threat Protection exclusions. You can also temporarily disable real-time protection.

Settings > Security > Virus & threat protection > Manage settings > Add or remove exclusions.

⚠️
False Positive Notice: Externals are often flagged as "False Positives" due to their memory reading methods. Adding an exclusion ensures the files are not removed.
03

Launch Roblox

Open Roblox and get to the home page Note: If you join a game while launching the external the external may crash. Please stay on the home screen.

04

Run External as Admin

Navigate to the extracted folder and locate Nebula Services.exe. Right-click and select "Run as Administrator" to launch the External

▶ Run "Nebula Services.exe" as Administrator
05

Wait for it to load and check for updates.

After launching the external, wait approximately 5 seconds for it to fully load and attach to the Roblox process.

⏳
Loading Time: Be patient the external will check for updates and make sure all offsets are working.
06

Open the Menu (Insert Key)

Once the external has finished loading, press the Insert key on your keyboard while in the Roblox game window. The Nebula menu should appear on-screen, confirming that everything is working correctly.

Menu Toggle: INSERT key
07

Toggles features and enjoy

With the menu open, you can toggle all of the feauteres you want.

Common Issues

Encountering problems? Check these common fixes below.

External closes immediately or file is missing.

This is almost always caused by Windows Defender. Go back to Step 02 and add the entire extracted folder to your exclusions list. Then re-extract the ZIP and try again.

Menu does not appear after pressing Insert.

Ensure that you waited the full 5 seconds after running the external. Also make sure Roblox is the active window (click on the game). If it still doesn't work, try running "Nebula Services.exe" as Administrator again.

"Nebula Services.exe" is not found.

Make sure you have extracted the entire ZIP folder. Some antivirus programs silently delete files. Temporarily disable real-time protection, re-extract, and add the folder to exclusions.

External randomly closes.

Leave the Roblox game and go back to home menu to relaunch the Nebula application as admininstrator again.

Does this work on all Roblox games?

Yes, Nebula works on the majority of Roblox games that do not have special anti-tamper protections. Avoid using it on games with strict anti-exploit systems.
