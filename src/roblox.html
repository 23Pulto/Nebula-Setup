Game Utility

Roblox External

A step-by-step tutorial to properly launch, attach, and configure the Nebula external tool for the Game.

Start Setup ↓
01

Download & Extract Release

Download the latest release ZIP folder and extract it to a clean dedicated location on your Desktop or local drive.

02

Security Exclusions

To avoid false positives from Windows Defender or third-party antivirus utilities, add the extracted folder to your exclusions list.

⚠️
False Positive Notice: Externals are frequently flagged due to memory reading techniques. Adding an exclusion ensures the binary is not deleted in the background.
03

Launch Game to Home Screen

Open the game's client and remain on the home screen.

💡
Important: Stay on the home screen before launching the external. Joining an active game during injection can cause crashes.
04

Run as Administrator

Locate Nebula Services.exe, right-click, and select "Run as administrator".

Run "Nebula Services.exe" as Administrator
05

Wait for Initialization

Wait approximately 5 seconds for the external to check for updates, verify game offsets, and attach to the process.

06

Join Game & Toggle Menu (Insert)

Join your chosen game session. Once in the Game, press the Insert key on your keyboard to toggle the menu interface and configure your desired features.

Common Questions & Fixes

Menu does not open when pressing Insert?

Click inside the Game window to ensure it is active. Also verify that you ran the application as Administrator.

Application closes randomly or won't start?

Check Windows Defender protection history. An exclusion must be active on the folder so Windows does not quarantine the files.
