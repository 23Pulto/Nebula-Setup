Fortnite Guide

Fortnite External Setup

Follow these ordered instructions carefully to install prerequisites, launch the loader, and access the in-game menu.

Start Setup ↓
01

Extract Loader from ZIP

Locate the downloaded ZIP file. Right-click it and choose Extract All to place the loader files into a dedicated folder on your Desktop.

💡
Never run files directly from inside the compressed ZIP. Always fully extract first.
02

Download Runtimes & DirectX (Uncheck Bing)

Ensure you have all necessary runtime dependencies installed so the application and overlay can render properly:

1. Download and install the Visual C++ Redistributable (2015-2022 x64).

https://aka.ms/vs/17/release/vc_redist.x64.exe

2. Download the DirectX End-User Runtime installer. During the setup wizard, uncheck the "Install the Bing Bar" checkbox before continuing.

https://www.microsoft.com/en-us/download/details.aspx?id=35
03

Run Loader as Administrator

Right-click the loader executable and select "Run as administrator".

⚠️
Notice: You may need to disable your Anti-Virus (Real-Time Protection) if the loader won't load or if the file gets automatically deleted by Windows.
04

Enter Your Key

When the console window appears and finishes checking for updates, paste your product license key and hit Enter.

Enter Key: [Paste your key here]
05

Launch Your Game

Start the Game from your game launcher and wait until you reach the main lobby.

06

Press Insert to Toggle Menu

Once in-game or in the lobby, press the Insert key on your keyboard to toggle the menu overlay on and off.

Common Issues & Fixes

Can't see the menu?

Switch your Game display mode to Windowed Fullscreen or Windowed. DONT USE FULL SCREEN, as exclusive full screen prevents external overlays from rendering on top of the game window.

Aim section doesn't work?

Make sure your FOV is toggled and expanded to the settings you want in the menu. If FOV is set to zero or off, aim assistance will not engage targets.

Some features don't work?

Please note that not all features work 100% of the time depending on game updates, server patches, and offset shifts. Check the community Discord for recent feature status.

Driver / Core Isolation Issues (Doesn't Work)

If the loader fails to communicate with your system or load drivers, you must disable Memory Integrity (Core Isolation) and Vulnerable Driver Blocklist in Windows Security:

Settings > Privacy & security > Windows Security > Device security > Core isolation details

Turn Memory Integrity and Microsoft Vulnerable Driver Blocklist to OFF, then restart your PC.

How do I turn off Anti-Virus?

Windows Defender can mistakenly block or delete the loader. Follow these steps to temporarily disable Real-time protection:

Windows Security > Virus & threat protection > Virus & threat protection settings (Manage settings) > Real-time protection > Turn OFF
