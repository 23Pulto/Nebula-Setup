FiveM Setup

A straightforward guide to installing, configuring dependencies, and running the external tool with the Game.

Start Setup ↓
01

Download & Extract Release

Download your build archive and extract the contents to a folder of your choice on your Desktop or main drive.

📁
Always ensure the archive is completely unzipped before attempting to run any files.
02

Security Exclusions

Add the newly created folder to your Windows Defender exclusions list to ensure memory inspection components aren't quarantined.

Windows Security > Virus & threat protection > Manage settings > Add exclusions > Folder

03

Install Visual C++ Redistributable

Ensure you have the latest 2015-2022 x64 VC++ packages installed.

https://aka.ms/vs/17/release/vc_redist.x64.exe
04

Launch the Game

Open the Game and remain on the main menu. In your Game graphics settings, ensure screen type is set to Windowed Borderless.

05

Run Loader & Toggle Menu

Right-click the loader and choose "Run as administrator". Once attached, join your desired server and press Insert to open the menu overlay.

Common Questions & Fixes

Menu does not render over the Game?

Check your graphics settings in the Game. Exclusive fullscreen blocks external overlays; switch to Borderless Windowed.

Does this work with custom server anticheats?

Compatibility depends on the server anticheat system. Refer to our Discord announcements for currently supported servers.
